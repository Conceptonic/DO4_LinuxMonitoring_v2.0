Продвинутый курс по мониторингу Linux-систем в реальном времени. Включает написание bash-скриптов для генерации файлов и логов, анализ nginx-логов, а также настройку полноценного стека мониторинга с визуализацией через Prometheus и Grafana.

Технологии и инструменты:

Bash (Shell scripting), C
Ubuntu Server 20.04 LTS
nginx (генерация логов в combined-формате)
GoAccess (анализ логов, веб-интерфейс)
Prometheus + Node Exporter (сбор метрик)
Grafana (дашборды, визуализация)
awk (парсинг логов)
iperf3, stress (нагрузочное тестирование)
df, cron
Git (GitLab, ветка develop)

Чему научился:

Генерация файлов и директорий по заданным параметрам с контролем свободного места на диске
Ведение лог-файлов: полный путь, дата создания, размер, время выполнения скрипта
Очистка файловой системы тремя способами: по лог-файлу, по дате/времени создания, по маске имени
Генерация реалистичных nginx-логов (случайные IP, коды ответов, методы, user-agents)
Парсинг и анализ логов через awk: сортировка по кодам, фильтрация ошибок, уникальные IP
Визуализация логов через GoAccess в браузере
Установка и настройка Prometheus и Grafana на виртуальной машине
Построение дашбордов: мониторинг CPU, RAM, диска, сетевого интерфейса
Нагрузочное тестирование системы (stress, iperf3) и наблюдение метрик в реальном времени
Написание собственного node_exporter: сбор метрик и отдача в формате Prometheus через nginx
